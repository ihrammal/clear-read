Accessibility Guide

Clear Read is designed for keyboard, screen-reader, low-vision, and visual use.

Keyboard use

Use Alt to enter the menu bar. Tab and Shift+Tab move through dialogs. F1 opens Help. F4 moves to the next low-confidence OCR word and Shift+F4 moves backward.

Screen readers

The main recognized-text area has an accessible name and remains editable. Status information reports OCR progress. Press Shift+F6 to focus the current status message if an automatic announcement is missed. Press F6 to return to the document; its text and selection are preserved. These actions are also available from the View menu. Startup and exit sounds and messages can be changed in Settings.

Low vision

Clear Read uses standard Windows controls and can follow Windows high-contrast and display-scaling settings. Accessible Reading Mode increases the document font size and spacing. The main menu wraps when the window is narrow; Find and Replace can be resized and scrolled. Screen-reader support and Windows high contrast are always available. Avoid relying on color alone when reviewing status or errors.

Arabic and bidirectional text

Arabic OCR and export use Unicode. Word export marks Arabic paragraphs and runs as right-to-left where detected.

Privacy

Arabic, English and French local OCR is free and the default. Optional API text correction and its key test are described in offline OCR and API setup. Offline Only Mode prevents optional API processing. API keys are stored separately using Windows protected credentials.
