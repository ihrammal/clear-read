Offline OCR and optional APIs

Free offline recognition

Clear Read recognizes Arabic, English and French using the bundled local OCR engine and language files. No account, Internet connection, subscription or API key is required. Leave Offline only mode enabled. Choose a language under OCR, open an image or PDF, and choose Recognize Document (offline). Review the result, especially numbers and names.

Optional online text correction

After local OCR, you can optionally send text to OpenAI, Google Gemini or Groq. This corrects text; it does not upload the original image/PDF. Each person supplies their own provider key. There is no shared developer key, automatic provider switching or automatic paid fallback. A failed or cancelled request preserves your original local text.

  1. Open Tools, API and AI Settings.
  2. Select OpenAI, Gemini or Groq. Read the provider's plan and privacy notice.
  3. Choose Create API key to open that provider's official website. Create a key in your own account, return here, and paste it into the API key field.
  4. Turn Offline only mode off when you want to use online features. Enter a model ID available to your account; the app suggests a separate default for each provider.
  5. Choose Test API key. This sends only a fixed short sample, never your document. A successful test means the selected provider returned a generated response using the current key and model. Invalid keys, unavailable models, permissions, quota and connection problems appear in the status field. The test consumes free quota or may incur a small charge according to your account plan.
  6. To enable document correction, select both document-sharing permission and API-assisted OCR text correction, then Save. Save before switching to another provider; each provider has its own saved key and model.
  7. In the editor, select the text to correct, or leave nothing selected to use the whole editor. Choose OCR, Correct text with selected API. The maximum is 12,000 characters per request; provider limits can require a shorter selection.
  8. Review the provider, character count and sharing confirmation. The request sends the chosen text to that provider only.
  9. Review the original and proposed text. Apply correction replaces only the sent text; Cancel retains the original. Undo restores an applied correction. OCR, Cancel API request cancels a pending request; a request already received by the provider may still consume quota or incur charges.

Free and paid plans

OpenAI API usage is generally paid. Gemini and Groq offer limited free-tier/plan access for eligible accounts, models and regions. Creating a key does not guarantee unlimited free usage. Limits, availability and provider terms can change; Clear Read cannot check your billing plan or cap provider charges. Google states that free-tier content may be used to improve its products. Use offline OCR when you do not want document text to leave your computer.

Key storage and removal

Keys are masked in the dialog and encrypted for the current Windows user with Windows Data Protection API. They are saved separately from settings.json and are not included in the application's source or release archives. Clear a selected provider's key field and Save to remove that saved key. Switching providers loads that provider's own saved key; save an edited key before switching. Turning offline-only mode back on prevents API correction and key tests, without deleting stored keys.

Image description, table reconstruction and custom providers are not available in this preview. AI text correction can change facts or numbers; review its proposals.
