Report a Problem

Choose Help, Report a Problem, or press Alt+H followed by P.

  1. Enter a summary and describe what actually happened. Add reproduction steps and expected behavior when possible.
  2. Review the report preview. Do not include passwords or private document content.
  3. Basic technical diagnostics are optional and off by default. They do not attach documents, file paths, API keys or logs.
  4. Choose Save report or Copy report to keep a local copy, or Email report to open a draft addressed to iman.rammal@gmail.com. You review and send it in your email application.

GitHub reports

Report on GitHub opens an issue draft at https://github.com/ihrammal/clear-read for you to review and submit. The app does not post issues automatically. You need GitHub access to the repository; a private repository only accepts reports from authorized users. Issues may be public when the repository is public.

For a large report, save the text file and attach it manually to your email or issue. If you close an unexported report, Clear Read offers to save it or keep editing.
