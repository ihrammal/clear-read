Keyboard Shortcuts

File commands

Ctrl+O: Open a document.

Ctrl+S: Save recognized text.

Ctrl+E: Export an accessible Word document.

Ctrl+Shift+S: Save text as a new file.

Editing and navigation

Alt: Enter the menu bar; press Alt again to leave and return to the previous control. Use arrows and Enter to navigate menus. Tab stays in the menu bar. Escape closes one submenu level at a time; Alt or F10 leaves menu navigation.

Ctrl+A: Select all document text.

Ctrl+X: Cut selected text.

Ctrl+C: Copy selected text.

Ctrl+V: Paste into the document.

Ctrl+F: Find text.

Ctrl+H: Replace text.

Ctrl+,: Open Preferences.

F6: Focus the document without changing the selection.

Shift+F6: Focus the current status message for screen-reader review. Press F6 to return to the document.

OCR commands

Ctrl+R: Recognize the current document.

Review commands

F4: Next low-confidence text.

Shift+F4: Previous low-confidence text.

Help

F1: Open help.
