# TextBridge 1.1 social media kit

Use the English or Arabic description with the corresponding images. Promotional cards are available as square (1080×1080), portrait (1080×1350), story (1080×1920), and landscape (1200×630) PNGs. The app and settings previews render actual updated interface controls with synthetic demonstration text; the cards are promotional artwork, not screenshots.

The package offers Express setup with bundled PaddleOCR, or Custom setup with Windows OCR and shortcut/folder choices. Windows OCR needs installed OS language packs. The full installer download includes Paddle even when a user chooses to omit it from disk.

Suggested image alt text:

- English app preview: TextBridge's editor displaying Arabic text with Arabic-Indic numerals, a French sentence with accents and œ, and English text.
- Arabic app preview: TextBridge's right-to-left Arabic interface displaying the same multilingual demonstration text.
- Settings preview: OCR settings with a choice of PaddleOCR or Windows OCR and document-language options.
- Promotional card: TextBridge 1.1. Read, edit and save text from images and scanned documents in Arabic, English and French. Choose PaddleOCR or Windows OCR.

Review recognized names and numbers. No general accuracy percentage or handwriting guarantee is claimed. Do not describe Windows OCR as having recognition confidence scores.
