# ClearRead OCR 0.11.0 — 14 October 2026

Historical rename milestone. The subsequent 0.11.1 PDF fix and current results are recorded in `QA-STATUS-0.11.1.md`; its hybrid-page behavior supersedes the limitation recorded below.

Continued from the 11 October Accessible OCR Studio 0.10.0 milestone.

## Changes

- Renamed visible product branding to ClearRead OCR: main window, welcome, settings, About, update messages, offline help, product metadata and installer shortcuts. Installer output is `ClearReadOCR-Setup-0.11.0.exe`.
- Preserved the internal executable name, installer AppId and legacy AppData settings/credential paths so existing preferences and protected keys remain available. An existing installation uses its remembered install directory.
- Added Save/Discard/Cancel before opening another file, replacing recognized text or exiting. Opening a new document clears the editor only after confirmation.
- Saves mark the exact text snapshot as saved only after successful writing. Cancelled or failed saves leave the operation cancelled. Cancelled Save As keeps the previous save path.
- Exit waits for conversion completion and prevents overlapping farewell handling.

## Verification

- Source/XAML/project XML and version validation passed.
- All 58 functional checks passed against the final source, including the existing multilingual OCR, export, mixed-page PDF, credentials and failure-cleanup tests and five new branding/unsaved-state checks.
- Self-contained Windows x64 publication succeeded in `D:\AOS\publish`.
- Inno Setup compiled `artifacts/ClearReadOCR-Setup-0.11.0.exe` successfully. Installation/upgrade/uninstallation of this package have not been tested in this session.
- NuGet vulnerability lookup failed during the initial restore. Cached dependencies were subsequently restored with vulnerability lookup disabled; no current vulnerability audit is claimed.

The automated checks verify unsaved-state tracking; they do not operate the native Save/Discard/Cancel dialog or independently verify screen-reader speech. Previous installer lifecycle results apply to 0.10.0, not this renamed package.

2. Repeat the remaining workflow matrix from the 11 October notes, including Recognition Review, preferences, exports, high contrast and 200% scaling.

4. Searchable PDF generation recognizes the original input; edits in the text editor are exported through text/DOCX/HTML/Markdown, not inserted into that PDF text layer.
5. Repeat installer lifecycle validation for the renamed package, including upgrade shortcuts and clean-machine administrative installation. Dependency/license review, signing and a current vulnerability audit remain release gates.
