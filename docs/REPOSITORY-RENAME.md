from ihrammal/clear-read to **ihrammal/textbridge**.

- Repository: https://github.com/ihrammal/textbridge

- Installer: https://github.com/ihrammal/textbridge/releases/download/v1.0.2/TextBridge-Setup-1.0.2.exe
- Update feed: https://api.github.com/repos/ihrammal/textbridge/releases/latest

The repository identity, history, tags, issues and released files were retained.
Anonymous checks verified the new and old feed addresses and fully downloaded
the installer through both repository names. Both copies match SHA-256
253c479b217e001b67136e8056ef952233abdcde72ac9e296a48a72e3ff40dc9.

The working Git remote and active documentation/captions use the canonical name.
Source settings migrate only the known old repository/feed addresses, preserving
custom endpoints. Published v1.0.2 binaries were not rebuilt or replaced; their
old URLs continue through GitHub redirects. The canonical defaults take effect
in the next app build. Historical release evidence retains the URLs used then.
