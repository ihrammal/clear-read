## Rebuild

Use .NET 8 SDK, or the SDK already installed in `.tools\dotnet`.

1. Run `scripts\setup-runtime.ps1` when runtime files are missing. Network access is needed for this setup step. It extracts dependencies into the project without installing Tesseract system-wide.
2. Run `scripts\validate-source.ps1`.
3. Run `scripts\test-windows.ps1`.
4. Run `scripts\build-windows.ps1`.
5. Launch `publish\AccessibleOCRStudio.exe`. Keep the entire publish directory together.
6. Run `scripts\build-installer.ps1` to produce `artifacts\AccessibleOCRStudio-Setup-0.10.0.exe` using Inno Setup 6.

The downloaded SDK, runtimes and build outputs are excluded by `.gitignore`. Runtime setup verifies the downloaded Tesseract, Poppler and ImageMagick archive SHA-256 hashes; language data currently comes from tessdata_fast's main branch.
