# Roadmap

## 0.1 Foundation
Accessible shell, menus, settings, welcome/exit experience, image OCR wiring, help.
## 0.2 Documents
PDF rendering, mixed PDFs, page navigation, batch jobs.
## 0.3 Structured export
DOCX/TXT/HTML/Markdown, headings, lists, RTL/LTR.
## 0.4 Advanced OCR
Preprocessing, confidence review, tables, reading order.
## 0.5 Optional AI
Provider-neutral API settings, protected credentials, correction and image descriptions.
## 0.6 Productization
Updater, installer, license/third-party notices, crash recovery.
## 1.0
Accessibility audit, NVDA/JAWS/Narrator test matrix, signed public release.
